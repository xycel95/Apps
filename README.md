## La misma estructura para todos los programas

Cada aplicación tendrá estos cuatro apartados, siempre en este orden:

| Apartado | Qué encontrarás |
| --- | --- |
| **Descripción del programa** | Para qué sirve, qué permite hacer y qué necesitas para utilizarlo. |
| **Cómo funciona y guía** | Primeros pasos, instrucciones de uso y explicación de sus opciones. |
| **Descargar** | Los archivos necesarios, la versión disponible y las indicaciones para instalar o actualizar. Si una descarga aún está pendiente, se indicará aquí. |
| **Notas de parche** | Los cambios de cada versión: la actualización más reciente arriba y las anteriores debajo. |

## Cómo irá creciendo

Cuando incorporemos otro programa, tendrá su propia entrada en esta lista y los mismos cuatro apartados. Cada aplicación conservará su espacio para organizar sus archivos y actualizaciones.

Cuando salga un parche, se actualizará su descarga y se añadirán sus novedades al principio de las notas de parche. Las notas anteriores se conservarán. Corregir una descripción o una guía no se anunciará como una nueva versión del programa.

Para continuar el desarrollo desde otra conversación, consulta las [instrucciones del repositorio](AGENTS.md). El [catálogo de metadatos](catalogo.json) mantiene los enlaces a la información de cada aplicación.
