# Notas de parche

## 1.0.0 — 15/11/2026

Primera versión de Sintonía para Windows x64.

- Selección inicial de 49 canales españoles con filtro conservador de procedencia.
- Importación de listas M3U por enlace o archivo y de emisiones directas.
- Buscador, categorías, favoritos y agrupación de señales alternativas.
- Pantalla completa, volumen, pausa y selección de audio cuando esté disponible.
- Actualización del catálogo y conservación de la última lista válida ante fallos.
- Ejecutable autónomo con .NET y LibVLC incluidos.

El filtro no certifica jurídicamente las emisiones y no se eluden DRM,
suscripciones ni restricciones geográficas. Las comprobaciones se documentan
en el apartado de descargas y en el informe de validación.
