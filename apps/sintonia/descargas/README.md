Esta versión viene **sin listas ni canales precargados**. Abre el ejecutable y
pulsa Añadir lista para incorporar tus propias fuentes.
No requiere instalar VLC ni .NET ni tener archivos al lado del EXE.

Si actualizas desde 1.0.0, se elimina exclusivamente la antigua lista automática.
Se conservan las listas importadas por ti, favoritos y volumen.
Cierra la versión anterior antes de abrir el nuevo ejecutable.
