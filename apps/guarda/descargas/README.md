# Descargar

**Guarda 1.0.1** · Windows 10/11 con .NET Framework 4.8 o 4.8.1.

- **[Descargar Guarda.exe](https://raw.githubusercontent.com/xycel95/Apps/guarda/apps/guarda/descargas/Guarda.exe)** — ejecutable portable. Puedes abrirlo directamente.
- **[Descargar el paquete completo](https://raw.githubusercontent.com/xycel95/Apps/guarda/apps/guarda/descargas/Guarda_v1.0.1_Completo.zip)** — ejecutable, código, guía y comprobaciones.

El paquete se entrega completo, sin bibliotecas adicionales de SSH Backup ni instalación de componentes propios. Requiere el .NET Framework indicado.

Para actualizar desde Copia Fácil, cierra la aplicación y utiliza `Guarda.exe`. Recupera sus preferencias cuando Guarda aún no tiene preferencias guardadas. No incluye un actualizador automático.

## Integridad y validación

Las huellas de ambos archivos están en [SHA256SUMS.txt](SHA256SUMS.txt). Son los mismos binarios de la entrega 1.0.1.

El motor se probó con archivos reales en Linux/Mono y se completó una copia desde la ventana. **Sigue pendiente probarla en Windows real y con un USB físico.** Consulta [VALIDACION.txt](../docs/VALIDACION.txt).
