# CorreoDiario

Guarda los correos del día en PDF y sus adjuntos originales por separado.
Incluye conexiones para Outlook web y para el Outlook clásico configurado en
el equipo. El movimiento a Eliminados es opcional y viene desmarcado.

**Primera beta.** La conexión real con cada cuenta y la impresión necesitan
comprobarse en el equipo de uso; no se garantiza cualquier servidor de Outlook.
