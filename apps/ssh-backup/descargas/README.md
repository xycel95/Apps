# Descargas de SSH Backup

## Entrega 2.1.0

**Pendiente de incorporar el ZIP original.** El código y la documentación están publicados; todavía no hay un enlace de descarga del ejecutable.

Archivo que debe incorporarse: **SSHBackup_Completo_2.1.0.zip**.

El registro de la entrega original indica estos hashes:

| Archivo | SHA-256 registrado |
| --- | --- |
| SSHBackup_Completo_2.1.0.zip | d4b4eae3c04395aa0c2aab2df6bde746978403c5229943f9ca8adda3deb741ed |
| SSHBackup.exe, dentro del ZIP | 2b9936b40e9a7676d38359db0921b96100ea892a61b32523de4bf40ff47358c9 |

Estos valores identifican la entrega que se debe recuperar; en esta sesión no se han vuelto a comprobar sus bytes porque no está disponible el archivo original.

## Al incorporar el archivo

1. Comprobar el contenido completo del ZIP, sus hashes y el paquete firmado incluido, conservando las licencias.
2. Confirmar que no contiene claves privadas, configuraciones reales, contraseñas ni datos de copias.
3. Subir el ZIP comprobado a esta carpeta y actualizar el archivo app.json de la aplicación con su ruta, URL, hash y disponibilidad real.
4. Comprobar que el archivo puede descargarse antes de anunciarlo como disponible.

## Cuando llegue una actualización

Publicar el paquete verificado de la nueva versión, actualizar app.json y añadir sus notas arriba de [Notas de parche](../notas-de-parche/README.md). Mantener las notas antiguas. Si se sustituye una descarga anterior, retirar su archivo solo después de comprobar el nuevo y corregir los enlaces afectados.

## Código fuente

El [código disponible en esta rama](../Codigo/) es un proyecto de desarrollo. El ZIP automático de código fuente que ofrece GitHub no equivale a la entrega completa con ejecutable y dependencias.
