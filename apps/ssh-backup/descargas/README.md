## Actualizar

Desde 2.2, **Herramientas → Actualizaciones → Comprobar actualizaciones**: el canal está preparado. Desde 2.0/2.1, abre el paquete 2.2.0 con **Abrir paquete** o pega una vez el [canal oficial](https://raw.githubusercontent.com/xycel95/Apps/ssh-backup/apps/ssh-backup/actualizaciones/stable.xml) y comprueba novedades. Desde 1.x, sustituye el EXE con el programa cerrado.

Termina las copias antes de instalar. Con el mismo usuario Windows y ubicación se conservan tus accesos, servidores, ajustes e historial. Si mueves el EXE, vuelve a guardar la programación.
