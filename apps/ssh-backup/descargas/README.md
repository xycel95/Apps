## Actualizar

Desde 2.2, **Herramientas → Actualizaciones → Comprobar actualizaciones** utiliza el canal preparado. Para este primer salto desde 2.0/2.1, termina las copias, cierra la app y sustituye `SSHBackup.exe` por el nuevo en la misma ubicación, con el mismo usuario Windows. La entrega 2.1 tiene una incompatibilidad en su instalador antiguo; desde 2.2 queda corregida. Desde 1.x también se sustituye el EXE.

Termina las copias antes de instalar. Con el mismo usuario Windows y ubicación se conservan tus accesos, servidores, ajustes e historial. Si mueves el EXE, vuelve a guardar la programación.
