# Descargar

**Bloques PDF 1.0.2** · Windows 10/11 · .NET Framework 4.8 o posterior.

**[Descargar BloquesPDF_1.0.2_Windows.zip](https://raw.githubusercontent.com/xycel95/Apps/bloques-pdf/apps/bloques-pdf/descargas/BloquesPDF_1.0.2_Windows.zip)**

El ZIP contiene **BloquesPDF.exe**, la guía de uso, el código fuente, las licencias y el informe de comprobaciones. No requiere instalar Python ni .NET 10.

1. Descarga y descomprime el ZIP.
2. Abre **BloquesPDF.exe**.
3. Añade los PDF y pulsa **Crear bloques** para elegir el destino.

Cada documento se añade una sola vez y la exportación contiene únicamente los PDF.

Si actualizas, cierra el ejecutable anterior y utiliza el nuevo. No hay un actualizador automático configurado.
