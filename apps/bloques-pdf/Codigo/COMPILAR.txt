BLOQUES PDF - COMPILACION NORMAL DE WINDOWS (1.0.4)

Requiere SDK .NET 10 y Windows 10/11 para las pruebas de interfaz.
El ejecutable final usa .NET Framework 4.8; el usuario no instala .NET 10.

Desde Codigo:
  dotnet build BloquesPDF.csproj -c Release -p:RestoreLockedMode=true

Se genera el EXE normal con sus DLL y BloquesPDF.exe.config en bin/Release/net48.
No se fusionan bibliotecas, no se usa ILRepack ni se ofusca el programa.
Distribuye todos esos componentes juntos; el usuario debe extraer el ZIP completo.

Preparar el ZIP en una carpeta nueva:
  powershell -File build/Pack-Windows.ps1 -OutputDirectory C:/BloquesPDF-paquete

Compilar, examinar el paquete con Microsoft Defender y probarlo en Windows:
  powershell -File build/Validate-Windows.ps1 -OutputDirectory C:/BloquesPDF-comprobacion

El script no desactiva la proteccion ni añade exclusiones. El analisis personalizado
incluye los archivos comprimidos e ignora exclusiones al usar DisableRemediation.
El informe registra firmas, versiones, huellas, pruebas nativas y el arranque del EXE.

El flujo .github/workflows/bloques-pdf-windows.yml ejecuta estos pasos en Windows
con fuentes de la revision exacta y publica la version solo si todas las pruebas pasan.
