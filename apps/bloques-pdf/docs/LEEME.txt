BLOQUES PDF 1.0.4 - XyceL

INICIO
Descomprime el ZIP completo y abre BloquesPDF.exe.
Conserva junto al EXE todas las DLL y el archivo BloquesPDF.exe.config.
Estos componentes forman parte del programa y no se exportan con tus PDF.
Windows 10/11 con .NET Framework 4.8 o posterior. No requiere Python ni .NET 10.
Los PDF se procesan en tu ordenador, sin enviarlos a servidores.

USO
1. Añade todos los PDF que quieras con Añadir PDF, arrastrando archivos o carpetas,
   o mediante Añadir carpeta. Puedes incluir subcarpetas.
2. Se proponen 50 PDF originales por bloque, con cantidad editable.
   La aplicación no impone un límite fijo al total de documentos añadidos.
3. Pulsa Crear bloques y elige dónde guardarlos.
4. Abre el resultado. Dentro de una carpeta nueva se guardan únicamente
   BLOQUE 1.pdf, BLOQUE 2.pdf, BLOQUE 3.pdf, etc.
   La carpeta utiliza el formato BloquesPDF_2026.11.06_21.09.19.
   Si coincide el segundo con otro trabajo, se añade (2), (3), etc.

CADA DOCUMENTO SE AÑADE UNA SOLA VEZ
No hay una opción de copias en el programa ni repeticiones internas.
100 PDF de una página -> dos bloques de 50 páginas.
103 PDF de una página -> tres bloques: 50, 50 y 3 páginas.
Los originales de varias páginas se conservan completos y en su orden.
Elige las copias que necesites en el cuadro de impresión de la impresora.
No se añaden portadas ni separadores en blanco.

EXPORTACIÓN
Solo se generan PDF. No se escriben CSV, TXT ni archivos de control en el destino.
Los errores se muestran dentro de la aplicación, en una ventana con desplazamiento.
Cancelar conserva únicamente los bloques completos y elimina el bloque en curso.
Los originales se abren para lectura y no se modifican.
Un PDF unido es una copia para impresión: valida las firmas digitales en los originales.

MODO DE CARPETAS
La opción Carpetas con los PDF firmados originales copia sus bytes sin modificarlos,
repartidos en carpetas BLOQUE 1, BLOQUE 2, etc. Tampoco añade informes auxiliares.

COMPROBACIONES Y LÍMITES
Se han superado 33 aserciones del motor y una comprobación del mismo EXE distribuido
cargado desde un host .NET 10. Se comprobaron 3.000 PDF en 60 bloques sin archivos extra.
Consulta el informe de la comprobacion nativa y del antivirus en la publicacion de GitHub.
No se ha probado una impresora fisica ni el antivirus corporativo del usuario.
El EXE no lleva firma Authenticode. No se garantiza la aceptación por el antivirus.
Se incluyen el código, las licencias y el informe de verificación para su revisión.
